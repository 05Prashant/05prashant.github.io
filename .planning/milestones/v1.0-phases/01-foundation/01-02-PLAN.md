    Create `src/styles/` directory and write `global.css` with the following exact content. This file is the single source of truth for all design tokens.

    ```css
    /* src/styles/global.css */

    /* =====================
       Design Tokens
    ===================== */
    :root {
      --color-bg: #1e2030;
      --color-text: #e8e8e8;
      --color-text-muted: #a0a0b0;
      --color-accent: #82aaff;
      --font-sans: -apple-system, BlinkMacSystemFont, 'Segoe UI', system-ui, sans-serif;
      --font-mono: 'JetBrains Mono', 'Fira Code', ui-monospace, monospace;
      --max-width: 1100px;
      --spacing-page: 1.5rem;
    }

    /* =====================
       FOUC Prevention
       Set on html AND body — html covers iOS overscroll area above the page.
       If only set on body, a white flash appears on load and on iOS pull-to-refresh.
    ===================== */
    html,
    body {
      background-color: var(--color-bg);
      color: var(--color-text);
    }

    /* =====================
       Reset
    ===================== */
    *,
    *::before,
    *::after {
      box-sizing: border-box;
      margin: 0;
      padding: 0;
    }

    /* =====================
       Base Styles
    ===================== */
    body {
      font-family: var(--font-sans);
      font-size: 1rem;
      line-height: 1.6;
      min-height: 100vh;
      -webkit-font-smoothing: antialiased;
      -moz-osx-font-smoothing: grayscale;
    }

    /* =====================
       Typography Scale
       clamp() ensures readable sizes across screen widths without breakpoints
    ===================== */
    h1 {
      font-size: clamp(1.75rem, 4vw, 3rem);
      font-weight: 600;
      line-height: 1.1;
    }

    h2 {
      font-size: clamp(1.25rem, 3vw, 2rem);
      font-weight: 600;
      line-height: 1.2;
    }

    h3 {
      font-size: 1.25rem;
      font-weight: 600;
    }

    p {
      line-height: 1.7;
    }

    /* =====================
       Layout Utility
    ===================== */
    .container {
      max-width: var(--max-width);
      margin: 0 auto;
      padding: 0 var(--spacing-page);
    }

    /* =====================
       Links
    ===================== */
    a {
      color: inherit;
      text-decoration: none;
    }

    a:hover {
      color: var(--color-text);
    }
    ```

    FOUC note: The `background-color` on `html` (not just `body`) is critical. The browser renders the `html` background before it fully applies `body` styles — setting only on `body` causes a white flash on load and on iOS overscroll. This is a pure CSS solution; no JavaScript needed.

    **src/layouts/BaseLayout.astro**
    ```astro
    ---
    import '../styles/global.css';
    import Nav from '../components/Nav.astro';

    interface Props {
      title: string;
      description?: string;
    }

    const {
      title,
      description = 'Portfolio of Prashant Khanchandani, Staff Product Designer',
    } = Astro.props;
    ---
    <html lang="en">
      <head>
        <meta charset="utf-8" />
        <meta name="viewport" content="width=device-width, initial-scale=1" />
        <meta name="theme-color" content="#1e2030" />
        <title>{title} — Prashant Khanchandani</title>
        {description && <meta name="description" content={description} />}
        <link rel="icon" type="image/svg+xml" href="/favicon.svg" />
      </head>
      <body>
        <Nav />
        <main>
          <slot />
        </main>
      </body>
    </html>
    ```

    Notes on BaseLayout:
    - Import `global.css` in the frontmatter (not via `<style is:global>`) — this is the simpler Astro 5 pattern
    - `<meta name="theme-color" content="#1e2030">` controls iOS status bar color and overscroll chrome color
    - The `<slot />` inside `<main>` is where page content renders
