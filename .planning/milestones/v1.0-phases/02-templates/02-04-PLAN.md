**Step 1 — Create `src/layouts/CvLayout.astro`:**

```astro
---
import BaseLayout from './BaseLayout.astro';

// Markdown pages in src/pages/ with a `layout` frontmatter property
// pass their frontmatter under Astro.props.frontmatter — NOT Astro.props directly.
// Using Astro.props.title directly would be undefined.
const { frontmatter } = Astro.props;
---

<BaseLayout title={frontmatter.title} description={frontmatter.description}>
  <div class="container cv-content prose">
    <slot />
  </div>
</BaseLayout>

<style>
  .cv-content {
    padding-top: 4rem;
    padding-bottom: 6rem;
    max-width: 720px;
  }

  .cv-content :global(h1) {
    margin-bottom: 2.5rem;
  }

  .cv-content :global(h2) {
    margin-top: 3rem;
    padding-top: 1.5rem;
    border-top: 1px solid rgba(255, 255, 255, 0.08);
  }
</style>
```

Critical: `const { frontmatter } = Astro.props` — NOT `const { title, description } = Astro.props`. Markdown pages pass frontmatter data nested under `.frontmatter`, not as top-level props. Getting this wrong causes `title` to be undefined and the page title renders as "undefined — Prashant Khanchandani".

Create `src/pages/404.astro`. Astro builds this to `dist/404.html`. GitHub Pages automatically serves this file for any URL that doesn't match a built route — no server configuration needed.

```astro
---
import BaseLayout from '../layouts/BaseLayout.astro';
---

<BaseLayout title="Page Not Found" description="This page doesn't exist.">
  <div class="container not-found">
    <p class="not-found-code">404</p>
    <h1>Page not found</h1>
    <p class="not-found-message">
      This page doesn't exist or has moved.
    </p>
    <a href="/" class="back-link">← Back to work</a>
  </div>
</BaseLayout>

<style>
  .not-found {
    padding-top: 8rem;
    padding-bottom: 8rem;
    text-align: center;
  }

  .not-found-code {
    font-size: clamp(4rem, 12vw, 8rem);
    font-weight: 700;
    color: var(--color-text-muted);
    line-height: 1;
    margin-bottom: 1rem;
  }

  .not-found h1 {
    margin-bottom: 1rem;
  }

  .not-found-message {
    color: var(--color-text-muted);
    margin-bottom: 2.5rem;
  }

  .back-link {
    display: inline-block;
    color: var(--color-accent);
    font-size: 1rem;
    text-decoration: underline;
    text-underline-offset: 3px;
  }

  .back-link:hover {
    opacity: 0.8;
  }
</style>
```

No special configuration needed. GitHub Pages serves `404.html` (built from `404.astro`) automatically for unmatched paths.
