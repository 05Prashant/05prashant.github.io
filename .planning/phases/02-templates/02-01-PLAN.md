Replace the stub `src/content.config.ts` with the full work collection schema.

Requirements:
- Import `defineCollection` from `'astro:content'`, `glob` from `'astro/loaders'`, `z` from `'astro/zod'`
- Use `loader: glob({ pattern: '**/*.md', base: './src/content/work' })` — glob loader is the Astro 5 API (`type: 'content'` is Astro 4, do not use)
- Use `schema: ({ image }) => z.object({...})` — schema MUST be a function receiving `image` as argument when any field uses `image()`. Plain `z.object()` makes `image()` unavailable.
- Schema fields:
  - `title: z.string()`
  - `company: z.string()`
  - `year: z.number()` — 4-digit integer, NOT `z.coerce.date()` which requires ISO string
  - `description: z.string()`
  - `heroImage: image()`
  - `cardImage: image()`
  - `cardImageSecondary: image().optional()`
  - `order: z.number()`
  - `draft: z.boolean().optional().default(false)` — allows entries to be hidden without deletion
- Export: `export const collections = { work };`

Critical: `src/content.config.ts` is at the `src/` level (not `src/content/config.ts` — that was Astro 4's location). This file already exists at the correct path; replace its content entirely.
