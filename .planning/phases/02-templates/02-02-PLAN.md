Key implementation notes:
- `getCollection('work', ({ data }) => !data.draft)` — always filter drafts; `getCollection` without filter returns ALL entries including drafts
- `entry.id` (not `entry.slug` — `slug` does not exist on Astro 5 collection entries)
- `href={/work/${entry.id}}` — backtick template literal for the URL
- `<Image src={entry.data.cardImage} alt={entry.data.title} />` — use `Image` from `astro:assets`, not a plain `<img>` tag
- `cardImageSecondary` is optional — always guard with `{entry.data.cardImageSecondary && (...)}`
- Empty `alt=""` on `cardImageSecondary` — it is decorative (tinted secondary panel)
